```
### 5. `[P1 - MAJOR]` Fragile whitespace splitting in `/proc/{pid}/stat` parser breaks process tree ancestry traversal when intermediate process names contain spaces.

- **Target:** `src/cli/commands/audit.rs:227`
- **Reporting Persona:** `rust-safety-auditor`
- **Description:** Fragile whitespace splitting in `/proc/{pid}/stat` parser breaks process tree ancestry traversal when intermediate process names contain spaces.
- **Failure Scenario:** On Linux systems, field 2 (`comm`) in `/proc/[pid]/stat` is enclosed in parentheses `(...)` and may contain arbitrary whitespace (e.g. `(cargo test)`, `(code helper)`, or binary paths with spaces). The current implementation calls `stat.split_whitespace().collect()` and assumes field 4 (`ppid`) is always located at index 3 (`parts[3]`). When any ancestor process name contains whitespace, `parts[3]` captures a token from within or immediately following the process name (such as the single-character process state `'S'`). `parts[3].parse::<u32>()` fails, which triggers an early `break` from the traversal loop. As a result, the recursion guard silently aborts its ancestor walk and fails to detect that an `argus` process exists higher in the process hierarchy.
- **Recommended Fix:**
```
- **Recommended Fix:** Locate the final closing parenthesis `)` using `stat.rfind(')')` to reliably delimit the end of the `comm` field, then parse the space-separated fields that follow:

```rust
fn is_recursive_audit() -> bool {
    if std::env::var("ARGUS_ACTIVE_AUDIT").is_ok() {
        return true;
    }

    #[cfg(unix)]
    {
        let mut pid = std::process::id();
        while pid > 1 {
            if let Ok(stat) = std::fs::read_to_string(format!("/proc/{pid}/stat")) {
                if let Some(rest) = stat.rfind(')').map(|idx| &stat[idx + 1..]) {
                    let parts: Vec<&str> = rest.split_whitespace().collect();
                    // Field 0 after ')' is state, field 1 is ppid
                    if parts.len() > 1 && let Ok(ppid) = parts[1].parse::<u32>() {
                        if ppid <= 1 {
                            break;

                            && comm.trim() == "argus"
                        {
                            return true;
                        }
                        pid = ppid;
                        continue;
                    }
                }
            }

        }
    }
```
